# Architecture

Reference Loader is a single ComfyUI V3 node pack. The root `__init__.py` is a thin entry shim; `backend/` owns the node, versioned state contract, media loading, manifest generation, and `/reference_loader` routes. `frontend/` owns the custom widget and editors and is bundled into one `dist/index.js` file.

The serialized `loader_state` is the portable media source of truth. It stores relative managed paths, source hashes, captions, ordering, enable flags, edit recipes, trim ranges, and display preferences—not media payloads or runtime preview state. A separate versioned `prompt` document stores text, dialogue blocks, and stable media mention IDs. Backend execution revalidates managed-path containment, file identity, output alignment, and prompt structure independently of the browser.

Reference Loader emits one `REFERENCE_LOADER_BUNDLE` runtime value so its media board is not vertically expanded by seven output sockets, plus one compiled prompt STRING intended for direct use or an intervening LLM. Reference Loader Raw Outputs unpacks the bundle into image, video, and audio lists rather than batches or montages. Caption lists come from the same output plan, while `manifest_json` records stable IDs and derivations without absolute paths or encoded media. VIDEO preserves its container audio; video-derived AUDIO is an explicit, separately enabled projection. Prompt mentions resolve against that same active per-type output plan at execution, preventing a saved mention from silently rebinding after reorder or disable operations.

Reference Loader Start/End Frames is a small I2V/L2V/FL2V/T2V projection of the bundle. It returns nullable scalar IMAGE values rather than ComfyUI output lists. The Combo defaults to FL2V; a connection-only optional STRING overrides it when non-blank. I2V maps the first enabled Image to `start_image`, L2V maps the last to `end_image`, FL2V maps the first two in enabled order, and T2V returns two `None` values. Missing frames remain `None`. Image-driven modes reject more than two enabled Images rather than silently selecting from an ambiguous set, while T2V ignores them because it consumes no frame.

The Loader's advanced `two_image_mode` boolean is frontend-only, socketless, and write-only. Its authoritative value lives in the node's namespaced frontend properties rather than `loader_state`; the native widget only writes through the display proxy and is synchronized back before queueing or workflow restoration. The controller blocks a third IMAGE enable action and adds further uploaded images with IMAGE disabled. It refuses to enable the mode when an existing workflow already has more than two enabled Images, avoiding implicit media-state mutation. Backend execution and fingerprints accept but ignore the proxy value, while Start/End Frames independently enforces the two-image runtime contract.

The Media DOM widget is its channel container's positioned offset parent. It measures the final channel's `offsetTop + offsetHeight` (plus the frame, with a 360px floor) and advertises that value as identical minimum and maximum heights. Offset geometry excludes previously assigned blank root height and is independent of canvas zoom. ComfyUI therefore lays out all Media content without an inner overflow region but does not allocate unrelated spare flex height to it, keeping the following Prompt widget adjacent.

Vue Nodes uses a separate CSS Grid layout and does not use the Legacy Canvas DOM-widget min/max values as its final row sizing. The Loader marks its owning `node-widgets` grid with `rl-reference-loader-widgets`; that grid uses `max-content` for the Media row and `minmax(180px, 1fr)` for Prompt. This overrides Vue Nodes' inline `auto auto` tracks, which otherwise stretch both widgets across the node's remaining flex height.

MiniMax H3 Reference to Video Wrapper is a model-specific projection of the same bundle. It uses manifest output IDs to pair enabled video-derived audio with its active video, treats audio from an inactive video as standalone audio, converts native VIDEO values to 24 fps IMAGE batches, and delegates conditioning and latent construction to ComfyUI's native `MiniMaxH3ReferenceToVideo.execute()` implementation.

Public contracts are intentionally independent from the source pack: node IDs `Alyac_ReferenceLoader`, `Alyac_ReferenceLoaderRawOutputs`, and `Alyac_ReferenceLoaderStartEndFrames`; bundle type `REFERENCE_LOADER_BUNDLE`; widget type `REFERENCE_LOADER`; state input `loader_state`; extension name `reference-loader.extension`; API prefix `/reference_loader`; and managed storage `input/reference_loader`.
