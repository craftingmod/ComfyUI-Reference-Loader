# 아키텍처

Reference Loader는 하나의 ComfyUI V3 커스텀 노드 팩이다. 루트의 `__init__.py`는 얇은 진입점 shim이고, `backend/`는 노드, 버전이 관리되는 상태 계약, 미디어 로딩, 매니페스트 생성, `/reference_loader` 라우트를 담당한다. `frontend/`는 커스텀 위젯과 에디터를 담당하며, `dist/index.js`는 첫 번째 커스텀 위젯이 생성될 때 Reference Loader 구현 청크를 지연 로드하는 작은 부트스트랩이다.

직렬화되는 `loader_state`는 이식 가능한 미디어 원본 상태다. 여기에는 상대 경로의 관리 대상 파일, 소스 해시, 캡션, 순서, 활성화 플래그, 편집 레시피, 트림 범위, H3 출력 설정, 표시 설정이 저장되며, 미디어 페이로드나 런타임 미리보기 상태는 저장되지 않는다. Load Reference Image는 `image_state` 아래에서 동일한 상태 계약을 사용하지만, 활성화된 이미지 하나와 오디오/비디오 항목이 없는 형태로 제한된다. 또한 표시 방식과 노드 계약에서는 캡션과 프롬프트 텍스트를 제외한다. 별도의 버전 관리 `prompt` 문서는 텍스트, 안정적인 미디어 멘션 ID, 그리고 안정적인 Subject ID의 순서가 있는 레지스트리를 저장한다. Subject 파트는 레지스트리 순서에 따라 `<Subject N>`으로 컴파일되지만 미디어 출력이 되지는 않는다. 백엔드 실행은 브라우저와 독립적으로 관리 대상 경로의 포함 관계, 파일 식별 정보, 출력 정렬, 프롬프트 구조를 다시 검증한다.

프론트엔드는 두 번째 업로드/에디터 스택을 만드는 대신 `single-image` 표시 모드를 가진 하나의 `ReferenceLoaderController`를 사용한다. 두 모드는 직렬화, reducer/history, API 라우트, 제한된 프록시 hydration, 이미지 편집, 소스 생명주기를 공유한다. 단일 이미지 모드는 공유 캡션 컨트롤을 숨기지만 Reference Loader의 캡션 동작은 변경하지 않는다. `REFERENCE_IMAGE_LOADER` 위젯은 Load Image 스타일의 선택기/미리보기/Edit 뷰를 선택하는 얇은 팩토리 어댑터이며 `preview_pixels`만 바인딩한다. 실행 전용 이미지 옵션은 ComfyUI의 기본 고급 위젯으로 유지된다. 백엔드의 `LoadReferenceImageNode`도 공유 reference parser, 소스 검증, 이미지 설정, 실행 fingerprint, 미디어 로더 위에 얹힌 얇은 projection이다. 공유 RGB/RGBA 텐서를 ComfyUI의 RGB IMAGE와 inverse-alpha MASK 계약으로 변환한다.

Reference Loader는 하나의 `REFERENCE_LOADER_BUNDLE` 런타임 값을 출력한다. 따라서 미디어 또는 프롬프트 출력 소켓을 개별적으로 추가해 미디어 보드가 세로로 늘어나지 않는다. 이 번들은 정규화된 프롬프트 상태와 컴파일된 문자열을 함께 보존한다. `[Reference Loader] Raw Prompt`는 번들을 검증하고 문자열을 `raw_prompt`로 추출한다. `[Reference Loader] Media Outputs`는 같은 번들을 이미지, 비디오, 오디오 목록으로 풀어내며 배치나 몽타주로 합치지 않고, 기존 출력 뒤에 nullable scalar인 `first_image` 편의 출력을 추가한다. 캡션 목록은 동일한 출력 계획에서 생성되고, `manifest_json`은 절대 경로와 인코딩된 미디어 없이 안정적인 ID와 파생 관계를 기록한다. VIDEO는 컨테이너 오디오를 유지하고, 비디오에서 파생된 AUDIO는 별도로 활성화할 수 있는 명시적인 projection이다. 실행 시 프롬프트 멘션은 동일한 활성 미디어 타입별 출력 계획을 기준으로 해석되므로, 저장된 멘션이 순서 변경이나 비활성화 이후 조용히 다른 미디어에 다시 연결되지 않는다.

`[Reference Loader] Start/End Frames`는 번들의 작은 I2V/L2V/FL2V/FL2V_LOOP/T2V projection이다. 이 노드는 ComfyUI 출력 목록이 아니라 nullable scalar IMAGE 값을 반환한다. Combo의 기본값은 FL2V이며, 비어 있지 않은 경우 연결만 된 optional STRING이 이를 덮어쓴다. I2V는 활성화된 첫 번째 Image를 `start_image`에 매핑하고, L2V는 마지막 Image를 `end_image`에 매핑한다. FL2V는 활성화 순서의 첫 두 이미지를 시작/종료 이미지로 매핑하고, FL2V_LOOP는 첫 번째 Image를 두 출력에 모두 사용하며, T2V는 두 출력에 `None`을 반환한다. 프레임이 없으면 `None`으로 유지된다. 이미지 기반 모드는 모호한 선택을 방지하기 위해 활성화된 Image가 두 개를 초과하면 자동으로 고르지 않고 거부한다. T2V는 프레임을 사용하지 않으므로 이미지를 무시한다.

Media DOM 위젯은 해당 채널 컨테이너의 위치 기준이 되는 offset parent다. 마지막 채널의 `offsetTop + offsetHeight`에 frame을 더한 값(최소 360px)을 측정하고, 그 값을 동일한 최소/최대 높이로 알린다. 별도의 H3 Timeline 위젯은 자체 intrinsic content height를 측정한다. Offset geometry는 이전에 할당된 빈 root 높이를 제외하며 canvas zoom과 독립적이다. 따라서 ComfyUI는 내부 overflow 영역을 만들지 않고 Media와 H3 콘텐츠를 배치하며, 다음 Subjects와 Prompt 위젯은 인접한 상태로 유지된다.

Vue Nodes는 별도의 CSS Grid 레이아웃을 사용하며 Legacy Canvas DOM 위젯의 min/max 값을 최종 행 크기로 사용하지 않는다. Loader는 소유한 `node-widgets` grid에 `rl-reference-loader-widgets`를 표시한다. 해당 grid는 Media, H3, Subjects 행에 `max-content`를 사용하고 Prompt에는 `minmax(180px, 1fr)`를 사용한다. 이 설정은 그렇지 않을 경우 모든 위젯을 노드의 남은 flex 높이만큼 늘리는 Vue Nodes의 인라인 `auto auto` 트랙을 덮어쓴다.

`[Reference Loader] MiniMax H3 Wrapper`는 동일한 번들을 사용하는 모델별 projection이다. 매니페스트 출력 ID로 활성화된 비디오 파생 오디오와 해당 비디오를 연결하고, 비활성 비디오의 오디오는 standalone audio로 취급한다. 일반 reference VIDEO 값은 MiniMax H3가 요구하는 24 fps IMAGE 배치로 변환하고, conditioning과 latent 생성은 ComfyUI의 네이티브 `MiniMaxH3ReferenceToVideo.execute()` 구현에 위임한다. Reference Loader는 실제 H3 `Frames`와 `FPS` 값을 `h3Output`에서 소유한다. 이 값은 `loader_state`에 저장되고 실행 projection에 포함되며 번들에도 전달된다. Timeline은 동일한 값을 읽기 전용으로 표시한다. 현재 Wrapper는 네이티브 H3의 24가 아닌 FPS를 native `length`로 `Frames`를 전달하기 전에 거부한다. Guide 전용 미디어는 일반 출력 계획이나 Prompt ordinal에 절대 추가하지 않는다. Guide source는 Image와 standalone Audio로 제한되고, Video와 비디오 파생 Audio는 일반 reference 전용 projection으로 남는다. Loader는 활성화된 timeline의 source ID를 런타임 전용 `guide_media` 매핑으로 디코드하며, 가능한 경우 활성 reference 객체를 재사용한다. 이후 Wrapper는 실제 AV latent frame 수를 사용해 R2V 뒤에 네이티브 `MiniMaxH3AddGuide` 행을 적용한다. 이 과정에는 Start `0`, End `-1`, 안정적인 프레임 순서, VAE 검사, visual/audio overlap 검증이 포함된다. Timeline이 꺼져 있으면 Add Guide 지원을 가져오거나 요구하지 않는다.

공개 계약은 소스 팩과 의도적으로 독립되어 있다. 주요 계약은 다음과 같다: 노드 ID `Alyac_ReferenceLoader`, `Alyac_LoadReferenceImage`, `Alyac_ReferenceLoaderRawPrompt`, `Alyac_ReferenceLoaderRawOutputs`, `Alyac_ReferenceLoaderStartEndFrames`; 번들 타입 `REFERENCE_LOADER_BUNDLE`; 위젯 타입 `REFERENCE_LOADER`, `REFERENCE_H3_TIMELINE`, `REFERENCE_IMAGE_LOADER`; 상태 입력 `loader_state`와 `image_state`; 확장 이름 `reference-loader.extension`; API prefix `/reference_loader`; 관리 대상 저장소 `input/reference_loader`.
