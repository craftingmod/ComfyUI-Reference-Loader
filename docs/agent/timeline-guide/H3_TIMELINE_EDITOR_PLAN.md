# H3 Timeline Guides 시간축 편집

## 논의 및 범위

기존 상단 Guide 나열을 시간 눈금과 배치 시각화로 확장한다. MiniMaxH3 Director의 시간축 조작 방식을 참고하되 기존 Reference Loader의 미디어 소유권, Guide manifest, native Wrapper 실행 계약을 유지한다. 구현 복잡도는 중간이며 새 라이브러리나 백엔드 변경 없이 진행한다.

첫 구현은 1) 시간축 표시, 2) 타이밍 조절, 3) 확대·스크롤 및 조작 안정화다. 출력 길이 자동 연동, 오디오 트리밍, 재생 헤드, 샷 프롬프트 편집은 포함하지 않는다. 이전 계획에서 제외했던 ruler를 이번 요청으로 추가한다.

## 화면과 데이터

- 24 fps를 기준으로 초와 프레임 눈금을 표시한다. 정수 frameIndex가 저장 기준이다.
- Image는 시점 마커, Audio는 적용된 crop 또는 로드된 메타데이터 길이의 막대다. 길이를 모르면 미확정 상태로 표시한다.
- Start는 0 프레임, End는 실제 출력 마지막 프레임에 대응하는 별도 앵커다. End를 표시 범위 끝의 확정 시각처럼 표현하지 않는다.
- 표시 범위는 배치와 오디오 길이를 포함하도록 자동 맞춤한다. 확대와 가로 스크롤은 편집 UI 상태이며 출력 duration을 바꾸지 않는다.
- 마커 선택은 기존 미디어 편집기와 연결한다. 프레임 직접 입력과 좌우 키 조절을 제공한다. 동일 Guide의 이미지와 오디오는 시간축에서 함께 이동한다.
- OFF, 비활성 미디어, 미완성 Guide를 식별한다. 오디오 구간 겹침은 경고하며 실제 출력 길이 및 오디오 샘플 기준의 최종 검증은 Wrapper가 담당한다.

## 편집과 수명 관리

- 시간축은 열린 편집기의 draft를 표시한다. 드래그 중에는 DOM 위치만 갱신하며 pointerup 때 draft를 변경한다. Apply 전에는 저장 상태를 바꾸지 않는다.
- Esc/pointercancel은 진행 중 드래그를 취소한다. 기존 Apply/Cancel과 Undo를 재사용한다. 다른 미디어의 미적용 편집은 덮어쓰지 않는다.
- 드래그 동안 전체 Loader 재렌더를 지연한다. pointer 좌표는 화면상 트랙 폭을 사용해 캔버스 확대율을 반영한다.
- 컨트롤러 제거·재렌더 시 이벤트를 정리하며 가로 스크롤을 보존한다. 좁은 노드에서 트랙만 가로 스크롤된다.

## 구현 순서

1. 독립적인 시간축 DOM 컴포넌트와 좌표/길이/겹침 계산을 추가한다.
2. Loader의 기존 draft, 선택, Apply/Cancel, 렌더 수명에 연결한다.
3. 기존 stylesheet에 눈금·마커·오디오·반응형 스타일을 추가한다.
4. 프레임 스냅, 페어 이동, 취소, Undo, 저장 복원, 확대 상태, 겹침 및 모르는 길이를 테스트한다.
5. typecheck, unit tests, lint, build와 diff 검사를 수행한다. 실제 ComfyUI UI 검증 가능 여부와 결과는 구분해서 기록한다.

## 검증 결과

### 구현 완료

- `frontend/src/reference-loader/components/h3-timeline.ts`: 초/프레임 눈금, Image 마커, Audio 구간, 별도 End 앵커, 1/2/4/8배 확대와 Fit, 가로 스크롤, 좁은 폭에서 겹치는 마커의 여러 줄 배치를 구현했다.
- 드래그와 좌우 키(Shift는 24프레임), 선택 Guide의 숫자 입력으로 전체 Guide를 이동한다. 드래그 중 화면만 갱신하고 놓을 때 기존 편집 draft에 반영한다. Esc, pointercancel, 창 포커스 상실은 진행 중 드래그를 취소한다.
- 기존 Apply/Cancel과 저장된 변경의 Undo/Redo를 재사용한다. 다른 미디어의 미적용 draft는 덮어쓰지 않는다. 기존 카드에서 숫자를 변경할 때의 채널 분리 동작은 유지하며, 시간축 조작은 연결된 두 채널을 함께 이동한다.
- Audio의 적용된 crop/메타데이터 길이, 비활성 상태, 미완성 배치 및 구간 겹침 경고를 표시한다. 기존 목록은 Placement details 안에 유지한다.
- 저장 스키마, manifest, 백엔드는 변경하지 않았다. 표시 범위와 확대 상태는 출력 길이를 변경하지 않으며, End의 실제 시각은 Wrapper 실행 시 결정된다.
- CSS 캐시 버전을 17로 올렸다. ComfyUI 페이지를 새로고침해 새 번들을 로드한다.

### 수행한 확인과 한계

- TypeScript 검사 통과. 기존 프런트엔드 전체 208개 및 후속 시간축 집중 테스트 8개 통과.
- 백엔드 194개 통과. 제한된 기본 캐시/임시 경로 대신 쓰기 가능한 테스트 경로를 사용했다.
- lint 통과. 전체 fmt:check는 기존 `THIRD_PARTY_NOTICES.md`, `docs/H3_GUIDE_CARD_EDITOR_PLAN.md`, `prompt-cache.ts`, `cards.css`의 포맷 차이로 실패했다. 해당 파일은 이번 작업에서 수정하지 않았다.
- 실제 Loader 컨트롤러를 사용하는 독립 브라우저 fixture에서 48f→72f 드래그, Apply, Undo, 400px 폭, 시간축 4배 확대 및 0.5배 CSS 캔버스 축소 상태의 이동을 확인했다.
- ComfyUI의 Legacy/Nodes 2.0에서의 실제 워크플로 실행과 생성 결과는 확인하지 않았다. 사용자 요청에 따라 추가 테스트는 중단하고 사용자가 직접 확인한다.
