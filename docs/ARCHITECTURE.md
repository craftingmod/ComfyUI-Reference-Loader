# Architecture

Reference Loader is a single ComfyUI V3 node pack. The root `__init__.py` is a thin entry shim; `backend/` owns the node, versioned state contract, media loading, manifest generation, and `/reference_loader` routes. `frontend/` owns the custom widget and editors and is bundled into one `dist/index.js` file.

The serialized `loader_state` is the portable media source of truth. It stores relative managed paths, source hashes, captions, ordering, enable flags, edit recipes, trim ranges, and display preferences—not media payloads or runtime preview state. Load Reference Image uses the same state contract under `image_state`, constrained to one enabled image and no audio/video entries, but its presentation and node contract omit captions and prompt text. A separate versioned `prompt` document stores text, stable media mention IDs, and an ordered registry of stable Subject IDs. Subject parts compile from their registry order to `<Subject N>` without becoming media outputs. Backend execution revalidates managed-path containment, file identity, output alignment, and prompt structure independently of the browser.

The frontend has one `ReferenceLoaderController` with a `single-image` presentation mode rather than a second upload/editor stack. Both modes share serialization, reducer/history, API routes, bounded proxy hydration, image editing, and source lifecycle. The single-image mode hides the shared caption control without changing Reference Loader's caption behavior. The `REFERENCE_IMAGE_LOADER` widget is a thin factory adapter that selects the Load Image-style chooser/preview/Edit view and binds only `preview_pixels`; execution-only image options remain native ComfyUI advanced widgets. The backend `LoadReferenceImageNode` is likewise a thin projection over the shared reference parser, source validation, image settings, execution fingerprint, and media loader. It converts the shared RGB/RGBA tensor to ComfyUI's RGB IMAGE plus inverse-alpha MASK contract.

Reference Loader emits one `REFERENCE_LOADER_BUNDLE` runtime value so its media board is not vertically expanded by individual media or prompt output sockets. The bundle retains the normalized prompt state and its compiled string. [Reference Loader] Raw Prompt validates the bundle and extracts that string as `raw_prompt`; [Reference Loader] Media Outputs unpacks the same bundle into image, video, and audio lists rather than batches or montages, and appends a nullable scalar `first_image` convenience output after its existing outputs. Caption lists come from the same output plan, while `manifest_json` records stable IDs and derivations without absolute paths or encoded media. VIDEO preserves its container audio; video-derived AUDIO is an explicit, separately enabled projection. Prompt mentions resolve against that same active per-type output plan at execution, preventing a saved mention from silently rebinding after reorder or disable operations.

[Reference Loader] Start/End Frames is a small I2V/L2V/FL2V/FL2V_LOOP/T2V projection of the bundle. It returns nullable scalar IMAGE values rather than ComfyUI output lists. The Combo defaults to FL2V; a connection-only optional STRING overrides it when non-blank. I2V maps the first enabled Image to `start_image`, L2V maps the last to `end_image`, FL2V maps the first two in enabled order, FL2V_LOOP maps the first Image to both outputs, and T2V returns two `None` values. Missing frames remain `None`. Image-driven modes reject more than two enabled Images rather than silently selecting from an ambiguous set, while T2V ignores them because it consumes no frame.

The Loader's advanced `two_image_mode` boolean is frontend-only, socketless, and write-only. Its authoritative value lives in the node's namespaced frontend properties rather than `loader_state`; the native widget only writes through the display proxy and is synchronized back before queueing or workflow restoration. The controller blocks a third IMAGE enable action and adds further uploaded images with IMAGE disabled. It refuses to enable the mode when an existing workflow already has more than two enabled Images, avoiding implicit media-state mutation. Backend execution and fingerprints accept but ignore the proxy value, while Start/End Frames independently enforces the two-image runtime contract.

The Media DOM widget is its channel container's positioned offset parent. It measures the final channel's `offsetTop + offsetHeight` (plus the frame, with a 360px floor) and advertises that value as identical minimum and maximum heights. Offset geometry excludes previously assigned blank root height and is independent of canvas zoom. ComfyUI therefore lays out all Media content without an inner overflow region but does not allocate unrelated spare flex height to it, keeping the following Prompt widget adjacent.

Vue Nodes uses a separate CSS Grid layout and does not use the Legacy Canvas DOM-widget min/max values as its final row sizing. The Loader marks its owning `node-widgets` grid with `rl-reference-loader-widgets`; that grid uses `max-content` for the Media row and `minmax(180px, 1fr)` for Prompt. This overrides Vue Nodes' inline `auto auto` tracks, which otherwise stretch both widgets across the node's remaining flex height.

[Reference Loader] MiniMax H3 Wrapper is a model-specific projection of the same bundle. It uses manifest output IDs to pair enabled video-derived audio with its active video, treats audio from an inactive video as standalone audio, converts native VIDEO values to 24 fps IMAGE batches, and delegates conditioning and latent construction to ComfyUI's native `MiniMaxH3ReferenceToVideo.execute()` implementation.

Public contracts are intentionally independent from the source pack: node IDs `Alyac_ReferenceLoader`, `Alyac_LoadReferenceImage`, `Alyac_ReferenceLoaderRawPrompt`, `Alyac_ReferenceLoaderRawOutputs`, and `Alyac_ReferenceLoaderStartEndFrames`; bundle type `REFERENCE_LOADER_BUNDLE`; widget types `REFERENCE_LOADER` and `REFERENCE_IMAGE_LOADER`; state inputs `loader_state` and `image_state`; extension name `reference-loader.extension`; API prefix `/reference_loader`; and managed storage `input/reference_loader`.
